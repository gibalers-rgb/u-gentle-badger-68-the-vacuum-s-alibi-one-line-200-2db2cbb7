One line, at most 200 characters, in which a robot vacuum explains why it missed a spot — written for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty ($5 prize pool).

The entry:

> My camera identified the spot as a pet. It has a name now — Crumb — and company policy forbids vacuuming pets, even the crunchy ones.

133 characters. Deadpan machine voice (camera identification, company policy), a named pet for the surprise turn, and the punch — "even the crunchy ones" — at the very end.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (validated: 1–200 characters, single line, no trailing newline).
